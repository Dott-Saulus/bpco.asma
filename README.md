# BPCO e asma in ambulatorio (GOLD 2026 · GINA 2026)

Pagina web statica, un solo file (`index.html`), senza dipendenze esterne.

## Pubblicazione su GitHub Pages
1. Crea un repository e carica `index.html` (e questo README).
2. Settings → Pages → Source: *Deploy from a branch* → branch `main`, cartella `/ (root)`.
3. La pagina sarà online su `https://<utente>.github.io/<repo>/`.

Le sezioni sono raggiungibili con link diretti, ad esempio `#bpco/terapia` o `#asma/riacut`.
